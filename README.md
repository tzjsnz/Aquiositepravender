# Projeto 0T001Z

Este projeto é uma landing page com opções de compra e suporte, utilizando:

- HTML, CSS e JavaScript para o frontend
- Java (Spring Boot) para o backend
- Python (Flask) para o backend

## Funcionalidades

- Exibição de opções de compra
- Botão de ajuda que revela informações de contato

## Como executar

### Frontend

Abra o arquivo `index.html` no seu navegador.

### Backend Java

1. Navegue até a pasta `backend-java`.
2. Compile e execute o projeto com o Spring Boot.
3. Acesse `http://localhost:8080/api/help` para ver a mensagem de ajuda.

### Backend Python

1. Navegue até a pasta `backend-python`.
2. Execute `python app.py`.
3. Acesse `http://localhost:5000/api/help` para ver a mensagem de ajuda.
